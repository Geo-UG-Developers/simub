# SIMUB · Reporte de emergencias

App de reportes para **Bomberos SIMUB Voluntarios, A.C.** (Guanajuato capital).
Desarrollada por **GEO UG Developers** (Universidad de Guanajuato / GeoUG), sin fines de lucro.

Mismo stack que IGNIS: PWA (Vite + TypeScript), Supabase, bot de Telegram (@SimubGtoBot), Web Push y panel.
